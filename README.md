# Intoduction

1. This is an Android App Project using Kotlin.
   You could use it as Reminder of Week Routines. 
2. The Init Data of Routines is set in Project code. 
   You could just modify the routine data 
   and regenerate the app(.apk file). 
3. You could add API interfaces to get data 
   from online database by yourself.


# Features

Version 1.0
1. Long-press a routine to mark it as completed for today.
   Short-press a routine to view its details.
2. Show a button that allows users to update current data
   when they resume the app after midnight.
3. Users can edit weekly and monthly routines now.

# Why This App is Good

1. Regular daily routines and weekly supplement intake
   are beneficial for health and productivity.
2. Privacy-Friendly. All data is stored locally on your phone.
3. Works Properly Without an Internet Connection.
4. A friendly UI (User Interface) for everyone, especially older adults.
